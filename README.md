# Квадрат — версия для сравнения

Снимок локального макета главной страницы v3 на 11 октября 2026.
Услуги и каталог — на светлом фоне, ипотека — на графитовом со светлыми карточками. Выбрана палитра «Нейтральный фарфор»: молочный фон, фарфоровые поверхности и голубые акценты. Четыре равнозначные карточки услуг получили самостоятельные нейтральные иллюстрации, уточняющие плашки и основные действия. Радиальное свечение на иллюстрированных карточках мягко следует за курсором; на карточках ипотеки широкое свечение входит и выходит через край.
Спецпредложения переключаются автоматически каждые 5 секунд с плавным переходом и возможностью паузы.
В конце страницы — один графитовый блок обратной связи без фоновой иллюстрации; до подвала сохранён самостоятельный композиционный отступ.
