# Квадрат — версия для сравнения

Снимок локального макета главной страницы v3 на 10 октября 2026.
Услуги и каталог — на светлом фоне, ипотека — на графитовом со светлыми карточками. Светлые поверхности и акценты используют голубые оттенки, фон страницы остаётся молочным. Иллюстрации покупки, продажи и калькулятора используют белые, нейтральные серые и серебристые материалы; общего цветового фильтра нет.
Спецпредложения переключаются автоматически каждые 5 секунд с плавным переходом и возможностью паузы.
В конце страницы — четыре варианта блока консультации для сравнения: молочный и графитовый, каждый без графики и с архитектурной иллюстрацией.
